# 使用说明

icpcBoard 面向 ICPC 区域赛银牌及以下常见知识点。第 1 章提供完整的竞赛实战说明，第 2 章按容器和算法逐项列出 C++17 方法、复杂度与常用组合；第 3～9 章保留简短的速查介绍和可复用模板。内容主要参照 OI Wiki，并按现场检索和黑白打印需求重新组织。

代码默认约定如下：

- 使用 C++17；节点通常从 1 编号，数组是否从 0 开始会在对应模板说明。
- 边权、距离、答案可能累加时优先使用 `long long`。
- 模板不替代题意分析；使用前必须核对数据范围、负权、重边、连通性和取模条件。
- “银牌及以下”不是严格题目标签。本手册保留常见基础模型，暂不收入高级多项式、复杂字符串数据结构、高阶数据结构及明显偏专项的技巧。
